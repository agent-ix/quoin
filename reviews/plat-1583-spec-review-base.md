# Base spec review of quoin PR 872 (PLAT-1583, FR-175 anomaly check fix-verification evidence)

## Summary

Ticket: PLAT-1583 (quoin half). Scope: `git diff origin/main...HEAD` at 5fbc1576, two files: the new FR-175 and one `spec/functional/index.md` line. Checked against merged quoin FR-136, FR-030, FR-120, NFR-035, StR-009 and the merged spec-artifacts-process FR-015, US-003 and its `tests/fixtures/anomaly` corpus (sibling checkout at origin/main 5907b9b), and against the existing `quoin-anomaly` crate and its test harness. Sub-analyses run: integrity (SR-17083), dependency (SR-17084), ears-conformance (SR-17085), evidence (SR-17086). AssuranceProfiles AP-201 and AP-202 cover finding quality and Jev lens evaluation, not the anomaly check, so neither applies; this is a direct review. `quire validate` (quire 0.44.0, engine 0.59.1) passes on both files with grammar 1/1 clean.

## Verdict

Changes requested. The number FR-175 does not collide: main holds up to FR-170, #871 holds FR-171..FR-174, #870 FR-180..FR-182 and #862 FR-166. The index entry is correct. There is no new evidence mechanism, compatibility layer, digest, pin, SHA or paywalled text. The outcome derivation matches FR-120 (`pass`/`fail`/`error`/`skip`) and FR-030 (newest run per suite by timestamp, absent store reads as empty). `skip` reads as `missing`, `error` as `failing`, and older runs and bindings never make a result `passing`, which matches StR-009-VC-2. The defects are in how a `Criterion` row is matched, how the criterion-only rule is justified, which targets FR-015 allows, whether the fixture rule can be met, and the severity chosen for a new check.

| FND-001 | medium | A Target matches only entries whose trace ids literally include it. FR-030-AC-15, which FR-175 itself cites ('A tool reports the id it knows'), says a run entry carrying a test-case id discharges the criteria that declare it. FR-030 counts that same criterion as discharged. Test-case ids and criterion ids are not matched the way FR-030 defines. Either resolve a Criterion Target through the obligation's declared test cases (quire-rs FR-053-AC-11) as FR-030 does, or state why this check departs from FR-030. | spec/functional/FR-175-anomaly-check-fix-verification-evidence.md:32-34, 52-53 |
