## Summary

Ticket: PLAT-166, PLAT-167. Frozen-head review of quoin#772 at 8291ec2, scoped to
`git diff origin/main...HEAD`. Rust lane (rust-review) folded in for the new test file.
Tools: quoin 0.29.1, quire 0.36.2 (engine 0.50.2).

Template check, measured: both template bodies, with stub entry points, were built with
`cargo check` against libfuzzer-sys 0.4 and arbitrary 1.5 (derive). Both new wrapper forms
compile with zero warnings. A control file with the old form (`/// Trace:` directly above

invocations"). The fix works, and `fuzz_target!(|data: &[u8]| f(data))` / `|input: Input| f(input)`

(carrier on the named wrapper `fn`), the template's "Why a named wrapper" section, SKILL.md
step 0 / outcome table, and FR-038 body and AC-4 agree on both changes. Stale "tooling"
wording remains in three skill places (FND-004).
