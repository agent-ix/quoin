## What runs today

Quoin now documents a baseline workflow for preparing requirements, risk and
verification evidence, approvals, release records, and a dossier for human
review. The guide explains the intended use and limits: Quoin organizes
authored inputs and reports; qualified people and the responsible organization
make risk, class, acceptability, and release decisions. A passing command does
not establish regulatory or standards compliance, and the workflow does not
replace product validation or the organization's quality system.

Help output now describes `--class-policy` on `quoin matrix` and
`quoin evidence audit`, and `--subject` on
`quoin evidence export-test-result`. The guide also directs users to run each
Engineering Assurance command with `--schema request` before submitting its
request. These schemas are owned by Engineering Assurance; this note does not
assert that the option is available until its implementation is released.
