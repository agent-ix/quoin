# Span Grounding Controls

## Acceptance Criteria

| ID | Criteria | Verification |
|----|----------|--------------|
| FR-001-AC-1 | A finding whose key is absent from the merged map defaults to warning. | Test (TC-1095) |
| FR-001-AC-2 | A draft that is frontmatter-less loads exactly one warning. | Test (TC-1095) |
| FR-001-AC-3 | Each of the 6 Locator primitives is exercised by a unit test. | Test (TC-1095) |
| FR-001-AC-4 | A section body pattern rule produces no finding when the named section matches, and one finding when it is present. | Test (TC-1095) |
| FR-001-AC-5 | Each cached entry expires after the configured interval. | Test (TC-1095) |
