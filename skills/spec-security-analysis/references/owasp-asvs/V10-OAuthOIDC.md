# V10 - OAuth and OIDC

**Area**: OAuth and OIDC  
**Focus**: OAuth 2 and OpenID Connect

## When to Apply

Apply when your component:
- Acts as an OAuth client, resource server or authorization server
- Acts as an OIDC client or provider
